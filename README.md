# Trabalho_PW_Culturas-Agricolas
Trabalho de desenvolvimento disciplina de Programação WEB. O assunto escolhido foram culturas agrícolas

Para rodar o projeto deve-se rodar os comandos npm i no server para instalar dependências, seguido de npm run start:dev para iniciar o servidor.

No cultura-frontend rode yarn i para dependências e yarn start para iniciar aplicação.
